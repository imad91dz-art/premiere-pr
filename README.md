# premiere-pr

Un petit projet de démonstration pour apprendre à ouvrir une pull request sur GitHub.

## Contenu

- `salutation.js` : une fonction qui renvoie un message de bienvenue.

## Utilisation

Ouvrez un terminal dans ce dossier et lancez :

```
node salutation.js Imad
```

Le programme affiche un message de bienvenu personnalisé.
